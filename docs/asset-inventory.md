# Asset Inventory

## Status definitions

- Planned: required but not selected.
- Candidate: source identified; license or suitability not yet verified.
- Approved: source, license, dimensions, and intended use verified.
- Integrated: approved asset implemented and tested.

## Approval checklist

- [ ] Source and license recorded
- [ ] Attribution requirements recorded
